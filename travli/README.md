# Travli

Travli is a React application for travel plans. Users can create, edit, view, and delete trips through a simple interface.

## Features

- Create new trips
- Edit existing trips
- Delete trips
- View trip details
- Search and filter trips
- Sort trips
- Switch between list and grid views

## Built With

- React
- Vite
- Axios

## How to run

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Install dependencies.

```bash
npm install
```

3. Start the development server.

```bash
npm run dev
```

The application expects the backend API to be running on:

```
http://localhost:3001
```
